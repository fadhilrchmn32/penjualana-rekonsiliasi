# RPC_CONTRACT — App 1 (Penerimaan & Setoran)

Semua RPC mutasi di PostgreSQL berjalan sebagai `SECURITY DEFINER` (`search_path = ''`), mewajibkan `auth.uid()` aktif, memeriksa `memberships` (company + branch + role), mengunci baris secara deterministik (`FOR UPDATE`), mengecek `idempotency_key`, dan mencatat `audit_events` + `accounting_events` secara atomik. **Aktor selalu diambil dari sesi (`auth.uid()`), tidak pernah dari payload klien.**

---

## Daftar RPC Minimum App 1

| Nama RPC | Peran Diizinkan | Parameter Utama | Efek & Validasi Kritis |
| :--- | :--- | :--- | :--- |
| `create_receipt_draft` | `finance_maker`, `finance_checker`, `collector_optional` (khusus tunai miliknya) | `p_idempotency_key`, `p_company_id`, `p_branch_id`, `p_receipt_channel`, `p_customer_paid_at`, `p_bank_value_date`, `p_fund_account_id`, `p_customer_id`, `p_is_unknown_identity`, `p_sender_name_raw`, `p_customer_gross_amount`, `p_bank_net_amount`, `p_bank_fee_amount`, `p_bank_fee_bearer`, `p_bank_reference`, `p_optional_invoice_ref`, `p_receipt_book_no`, `p_actual_collector_id`, `p_sales_owner_id`, `p_location_note`, `p_notes`, `p_evidence_hash` | Membuat nomor dokumen server-side (`RCV-TRF-YYYYMM-XXXX` / `RCV-TUN-YYYYMM-XXXX`). Mendeteksi indikasi duplikat tanpa menghapus otomatis. |
| `submit_receipt` | `finance_maker`, `finance_checker`, `collector_optional` | `p_idempotency_key`, `p_receipt_id`, `p_expected_version` | Mengubah `draft` → `waiting_verification`. Jika tunai, menambah `unverified_reported_balance` (bukan `verified_balance`). |
| `verify_receipt` | `finance_checker` (≠ `created_by` & `submitted_by`) | `p_idempotency_key`, `p_receipt_id`, `p_expected_version`, `p_verification_method`, `p_bank_statement_line_id`, `p_verification_ref`, `p_verification_note`, `p_bank_value_date`, `p_bank_fee_amount`, `p_bank_fee_bearer` | Transfer: mencocokkan mutasi bank (`bank_matches`) atau catatan pemeriksaan manual; memisahkan biaya bank. Tunai: menaikkan `cash_custody_accounts.verified_balance` & `custody_movement_sources`. Memancarkan `accounting_events`. |
| `reject_receipt` | `finance_checker` (≠ maker) | `p_idempotency_key`, `p_receipt_id`, `p_expected_version`, `p_reason` | Menolak penerimaan dengan alasan wajib; menurunkan `unverified_reported_balance` jika tunai. |
| `propose_receipt_identity` | `finance_maker`, `finance_checker`, `sales_admin` | `p_idempotency_key`, `p_receipt_id`, `p_expected_version`, `p_proposed_customer_id`, `p_reason` | Mengusulkan pelanggan untuk kasus `unknown_sender`. |
| `approve_receipt_identity` | `finance_checker`, `reconciliation_reviewer` (≠ pengusul) | `p_idempotency_key`, `p_receipt_id`, `p_expected_version`, `p_customer_id`, `p_reason` | Mengesahkan `customer_id`, menutup kasus `unknown_sender`, memancarkan event `receipt_identity_resolved`. |
| `create_cash_deposit` | `finance_maker`, `finance_checker`, `collector_optional` | `p_idempotency_key`, `p_company_id`, `p_branch_id`, `p_collector_staff_id`, `p_target_type`, `p_target_fund_account_id`, `p_deposit_date`, `p_lines`, `p_is_planned_partial`, `p_notes` | Memvalidasi sumber berasal dari `custody_movement_sources` terverifikasi dan `declared_amount <= remaining_amount`. |
| `submit_cash_deposit` | `finance_maker`, `finance_checker`, `collector_optional` | `p_idempotency_key`, `p_deposit_id`, `p_expected_version` | Mengubah `draft` → `submitted`. |
| `accept_cash_deposit` | `finance_checker` (≠ pembuat & pengaju) | `p_idempotency_key`, `p_deposit_id`, `p_expected_version`, `p_received_amount`, `p_bank_statement_line_id`, `p_notes` | Mengunci `cash_deposits`, `cash_custody_accounts`, `custody_movement_sources` (`FOR UPDATE`). Menangani setoran parsial vs kurang setor (`discrepancy_cases` tanpa menambah piutang). Setor langsung ke bank wajib memilih mutasi bank dan membuat `bank_matches` tanpa receipt ganda. |
| `create_internal_fund_transfer` | `finance_maker`, `finance_checker` | `p_idempotency_key`, `p_company_id`, `p_branch_id`, `p_transfer_date`, `p_from_fund_account_id`, `p_to_fund_account_id`, `p_amount`, `p_reference_no`, `p_notes` | Mencatat pemindahan kas kantor ke bank atau antar rekening perusahaan. |
| `approve_internal_fund_transfer` | `finance_checker` (≠ pembuat) | `p_idempotency_key`, `p_transfer_id`, `p_expected_version`, `p_bank_statement_line_id` | Menyetujui transfer internal dan memancarkan `internal_fund_transfer_approved`. |
| `import_bank_statement_preview` | `finance_maker`, `finance_checker`, `accountant` | `p_idempotency_key`, `p_company_id`, `p_fund_account_id`, `p_file_name`, `p_file_hash`, `p_period_start`, `p_period_end`, `p_date_format`, `p_decimal_format`, `p_opening_balance`, `p_closing_balance`, `p_rows` | Menyimpan staging batch, raw row, external txn ID & SHA-256 fingerprint, serta menandai potensi duplikat. |
| `commit_bank_statement_import` | `finance_maker`, `finance_checker`, `accountant` | `p_idempotency_key`, `p_batch_id`, `p_expected_version` | Mengubah batch `preview` → `committed` secara idempoten. |
| `propose_bank_match` | `finance_maker`, `finance_checker`, `reconciliation_reviewer` | `p_idempotency_key`, `p_company_id`, `p_items`, `p_notes` | Membentuk `match_group_id` untuk pencocokan 1:1, 1:N, atau N:1 sambil mengecek sisa mutasi. |
| `approve_bank_match` | `finance_checker`, `reconciliation_reviewer` (≠ pengusul) | `p_idempotency_key`, `p_company_id`, `p_match_group_id`, `p_notes` | Mengunci baris mutasi (`FOR UPDATE`) agar tidak pernah dipakai dua kali. |
| `request_receipt_reversal` | `finance_maker`, `finance_checker` | `p_idempotency_key`, `p_receipt_id`, `p_expected_version`, `p_reason` | Mengubah `verified` → `reversal_requested`. |
| `approve_receipt_reversal` | `finance_checker`, `accounting_approver` (≠ pemohon) | `p_idempotency_key`, `p_receipt_id`, `p_expected_version`, `p_reason` | Menolak reversal jika masih ada `payment_allocations` aktif, `customer_refunds` aktif, atau tunai sudah disetorkan. |
| `list_collection_dashboard` | Semua anggota perusahaan terotorisasi | `p_company_id`, `p_branch_id`, `p_date_from`, `p_date_to` | Mengembalikan jumlah dokumen dan total nominal terpisah untuk 7 indikator ringkasan. |
| `get_collector_custody_detail` | Finance/Admin/Viewer atau `collector_optional` (hanya miliknya) | `p_company_id`, `p_collector_staff_id` | Mengembalikan saldo terverifikasi, belum terverifikasi, rincian sumber receipt, dan histori mutasi penagih. |
